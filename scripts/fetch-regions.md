# 行政区划表的获取与更新

## 为什么是手动

一年更新一次的数据，不值得维护定时任务和抓取失败告警；
而且民政部页面改版会让定时任务默默失败，反而比手动更新更不可靠（docs/design.md §6）。

## 数据源

民政部每年公布《中华人民共和国行政区划代码》：
https://www.mca.gov.cn/mzsj/xzqh/

## 步骤

1. 从上述页面下载**当年**及**往前三年**的区划代码表。
   往前三年是必须的——SC 证按发证当时的区划编码，只用最新表会查不到老证的产地。

2. 整理成如下结构，每个年度一个文件放在 `data/regions-<年份>.json`：

   ```json
   {
     "来源": "民政部行政区划代码",
     "年份": "2025",
     "抓取日期": "2026-08-27",
     "数据": { "110101": "北京市东城区", "...": "..." }
   }
   ```

3. 用 `node scripts/seed.js` 灌进云数据库的 `regions` 集合。
   同一个区划码在多个年度都存在时，以最新年份为准；
   只在老年份出现的码也要保留，这正是覆盖历史区划的意义。

## 校验

灌完后，拿几个家里现成包装上的 SC 号跑一遍，确认产地能解出来。
解不出来不是错误——按设计，查不到就显示「可能为历史区划」，绝不判为非法。
